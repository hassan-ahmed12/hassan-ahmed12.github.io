# Hassan Ahmed portfolio

A two-page static portfolio; no WordPress, database, install, or build step is required.

## Edit

- `dist/index.html`: homepage, experience, services, and contact.
- `dist/work/index.html`: Work page introduction and contact.
- `dist/projects.js`: project names, platform tags, links, categories, and local image paths.
- `dist/styles.css`: shared design and responsive layouts.
- `dist/site.js`: project rendering and accessible platform filters.

Project images are website imagery from the linked brands, not claims that Hassan designed the photography or every feature shown. Specific development contributions can be added once supplied. Keep internal planning files and the LinkedIn source PDF out of the published directory.
